# Robot Framework Examples

Example Robot Framework files for CXTM test automation.

## fix.robot

This is a template for AI-generated fix scripts. The actual content is dynamically generated by the AI based on diagnostic analysis.

### Structure

```robot
*** Settings ***
Documentation     AI-Generated Fix - <description>
Library  CXTA
Resource  cxta.robot
...

*** Test Cases ***
Apply AI Generated Fix
    Apply Fix Configuration

*** Keywords ***
Connect To All Devices
    FOR    ${device}    IN    @{devices}
        Connect To Device "${device}"
    END

Apply Fix Configuration
    FOR    ${device}    IN    @{devices}
        Select Device "${device}"
        Configure    <IOS-XR commands>
        Configure    commit
    END
```

### CXTA Syntax Rules

1. `Connect To Device "${device}"` - Single space, quoted variable
2. `Select Device "${device}"` - Single space, quoted variable
3. `Configure    command` - Four spaces, NO quotes around command
4. Each IOS-XR command needs full path (e.g., `no ipv4 access-list ACL_NAME 5`)
5. Always end with `Configure    commit`

### Example Fix

```robot
Apply Fix Configuration
    FOR    ${device}    IN    @{devices}
        Select Device "${device}"
        Log To Console    Applying fix to ${device}
        Configure    no ipv4 access-list SEC_HARDENING 5
        Configure    no ipv4 access-list SEC_HARDENING 10
        Configure    ipv4 access-list SEC_HARDENING 5 permit tcp any eq bgp any
        Configure    ipv4 access-list SEC_HARDENING 10 permit tcp any any eq bgp
        Configure    commit
    END
```
